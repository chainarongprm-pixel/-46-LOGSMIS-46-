LOGSMIS v4.0
บัญชีคุมสิ่งอุปกรณ์พลาธิการ — กรมทหารพรานที่ ๔๖
รหัส รายการสิ่งอุปกรณ์ NSN อัตราอนุมัติ รับทั้งสิ้น จ่ายหน่วย คงคลัง ใช้การได้ ซ่อม รอจำหน่าย สถานะบัญชี

สร้างใบเบิก / ใบส่งคืนสิ่งอุปกรณ์ (แบบพิมพ์ ทบ.400-006)

เลขที่เอกสาร ประเภท หน่วย รายการ สป. จำนวน ผู้ดำเนินการ / ผู้ตรวจ สถานะ การจัดการ

ส่งซ่อมบำรุงสิ่งอุปกรณ์ (DB_REPAIRS)

เลขที่ใบซ่อม หน่วย รายการ ส่งซ่อม / รับคืน อาการชำรุด สถานะ รับคืนจากการซ่อม

เสนอจำหน่ายสิ่งอุปกรณ์ (แบบพิมพ์ ทบ.400-065)

เลขที่จำหน่าย หน่วย รายการ จำนวน เหตุผล / คณะกรรมการ สถานะ การดำเนินการ

ตารางกระทบยอดสิ่งอุปกรณ์ 19 หน่วย (ยอดรวมทั้งกรม + 18 หน่วยขึ้นตรง)

คำนวณแบบ Real-time จากฐานข้อมูลกลาง ไม่ต้องแยก 19 ชีต ลดความเสี่ยงข้อมูลไม่ตรงกัน

กดปุ่ม "โหลดข้อมูลกระทบยอดล่าสุด" เพื่อแสดงตารางเปรียบเทียบยอดทั้ง 18 หน่วย

บันทึกการตรวจสอบยอดสิ่งอุปกรณ์ประจำ 6 เดือน / เปลี่ยนตัวผู้รับผิดชอบ (ทบ.400-011)

เปรียบเทียบยอดตรวจนับจริงกับยอดตามบัญชีคุมของหน่วย

ประวัติการเคลื่อนไหวบัญชีสิ่งอุปกรณ์ (DB_TX_LEDGER ล่าสุด 50 รายการ)

เวลา ประเภท เลขที่อ้างอิง หน่วย รายการ เปลี่ยนแปลง คลัง (ก่อน→หลัง) ผู้ดำเนินการ

ตั้งค่าการแจ้งเตือน Real-time (Telegram Bot / LINE Messaging API)

Token ทั้งหมดจะถูกเข้ารหัสเก็บใน Script Properties โดยไม่แสดงค่าใน Google Sheets (LINE Notify ยุติให้บริการแล้ว แนะนำใช้ Telegram หรือ LINE Messaging API)

บันทึกรับสิ่งอุปกรณ์เข้าคลังหน่วย

เปลี่ยนรหัสผ่าน PIN 6 หลัก
